# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## 项目概述

基于 Docusaurus 3.9.2 的技术文档站点，记录 Docker、K8s 及其他工具的使用文档，部署至 GitHub Pages（`https://iuin8.github.io/doc-record`）。

## 常用命令

```bash
pnpm install          # 安装依赖（Node >= 20）
pnpm start            # 启动开发服务器（热重载）
pnpm build            # 构建生产版本
pnpm serve            # 本地预览构建结果
pnpm clear            # 清理缓存和构建文件
pnpm typecheck        # TypeScript 类型检查
```

### 国际化 / 翻译（Crowdin）

```bash
pnpm write-translations        # 生成翻译模板
pnpm crowdin:upload:download   # 上传源文件并下载翻译
pnpm crowdin:sync              # 完整同步（生成模板 + 上传 + 下载）
```

## 架构要点

### 侧边栏

`sidebars.ts` 使用 `autogenerated` 从 `docs/` 目录结构自动生成侧边栏。`docusaurus.config.ts` 中通过 `sidebarItemsGenerator`（`src/utils/sidebarGenerator.ts`）为每个 category 递归生成唯一 key，解决同名目录导致的重复 key 问题。

### 配置

- `docusaurus.config.ts` — 主配置，异步函数，根据 `DOCUSAURUS_CURRENT_LOCALE` 环境变量加载对应语言文案
- `docusaurus.config.localized.json` — 多语言标题/tagline
- 支持语言：`zh-Hans`（默认）、`en`、`zh-Hant`、`ja`
- 启用插件：本地搜索（支持中英文）、Mermaid 图表、KaTeX 数学公式

### 文档内容

- `docs/` — 主文档（`middleware/`、`tools/`、`materiel/` 等子目录，侧边栏自动生成）
- `blog/` — 博客文章
- `src/utils/sidebarGenerator.ts` — 自定义侧边栏 key 生成逻辑
- `static/` — 静态资源
- `temp/` — 被 Git 忽略的临时文件

### 部署

GitHub Actions（`.github/workflows/ci.yml`）自动部署：推送 main 后先快速构建基础版本，再同步 Crowdin 翻译后重新构建最终版本。

## 约定

- Front Matter 保持简洁，侧边栏由目录结构自动推导，无需手动配置
- 新文档放入 `docs/` 对应分类子目录，自动出现在侧边栏
- 提交信息使用约定式提交（Conventional Commits）：`feat:` / `fix:` / `chore:` / `docs:`

## Skill routing

When the user's request matches an available skill, ALWAYS invoke it using the Skill
tool as your FIRST action. Do NOT answer directly, do NOT use other tools first.
The skill has specialized workflows that produce better results than ad-hoc answers.

Key routing rules:
- Product ideas, "is this worth building", brainstorming → invoke office-hours
- Bugs, errors, "why is this broken", 500 errors → invoke investigate
- Ship, deploy, push, create PR → invoke ship
- QA, test the site, find bugs → invoke qa
- Code review, check my diff → invoke review
- Update docs after shipping → invoke document-release
- Weekly retro → invoke retro
- Design system, brand → invoke design-consultation
- Visual audit, design polish → invoke design-review
- Architecture review → invoke plan-eng-review
- Save progress, checkpoint, resume → invoke checkpoint
- Code quality, health check → invoke health
