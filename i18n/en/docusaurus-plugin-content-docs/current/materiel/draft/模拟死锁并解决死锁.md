## Simulate death lock

```sql
-- Transaction I

BEGIN;
-- perform actions such as updating one line of data in tables
UPDATE table_name SET column_name = 'test' WHERE column_name = 'test';
-- Attempting to get exclusive lock
SELECT * FROM table_name_2 WHERE column_name = 1 FOR UPDATE;
COMMIT;
```

```sql
-- Transaction II

BEGIN;
-- perform actions such as updating one line of data in tables
UPDATE table_name_2 SET column_name = 1 WHERE column_name = 1;
-- Attempting to get exclusive lock
SELECT * FROM table_name WHERE column_name = 'test' FOR UPDATE;
COMMIT;
```

## Resolve Deadlock

```sql
-- Method

-- View the dead locked sql and process Id
select pid,query,* from pg_stat_activity where datname='iuin' and wait_event_type = 'Lock';

-- You can only kill the selected statement, but
select pg_cancel_backend ('28736');
-- select, drop, and so on
select pg_terminate_backend ('2605');

-- Mode 2

-- See which Locks
select locktype,pid,relation,mode,granted,* from pg_locks where relation in (select oid from pg_class where relname='table_name');
Select pg_terminate_backend('process ID');

-- Test

-- Terminate all activated lock
select pg_terminate_backend(pid)
from pg_stat_activity
where state = 'active'
  and pid! pg_backend_pid()
  and pid in (select a id from pg_locks a joinin pg_class b on a.relation = b.oid where lower(b.relname) = 'news_content');

```

## pgsql Current threads and max threads

Maximum number of PostgreSQL connections：is obtained by postgresql.conf or SQL queries `SHOW max_connections;`.
当前连接数：通过 SQL 查询 `SELECT count(*), sum(case when state = 'active' then 1 else 0 end) FROM pg_stat_activity;` 获取。
