# Neural and parameter relations

## AI FAQ

> Question: Model of billions of parameters, what is the parameter here? Is it a neuron in the neurote?

Response:

The parameter in the billions of arguments model does not mean a neuron in the neuronet. The following is a specific description of：

### Meaning of model parameters

In the field of machine learning and artificial intelligence, the parameters of the model are the variables that the model learns from data in the course of training and is used to adjust the behaviour of the model to optimize predictive capabilities. With a simple linear regression model \(y = wx + b\) as examples, \(w\)(weight) and \(b\)(deviation) are the parameters of the model.The number and complexity of the parameters in the neurological network are more numerous and more complex, including the weight of the neurological connection and the bias of the neurology, which together determine how the neurological network processes and converts the input data to produce the corresponding output.

### Distinction from neurons

- **Concept different**：neurons are the basic component units of the neurological network that receive input signals, process them and produce output signals.Parameters are the values used to describe the properties of the connection strength, deviation, etc. between neurons.For example, in a simple pre-feedback neurological network, each neuron has several input connections, each of which corresponds to a weight parameter that determines the extent to which input signals influence the neuron activation.
- **Quantity relationships**：A neuron may have multiple parameters associated with it, but one parameter does not equate to a neuron.In the case of a neuron with \(\n\) input connections, it has \(n\) weights and \(1\) preferences with a total of \(n + 1\) parameters to describe the neuron properties.And in a neurological network with multiple neurons, the number of parameters increases dramatically as the number of neurons and the way they are connected. 比如，一个有 \(1000\) 个神经元的全连接神经网络，如果每个神经元有 \(1000\) 个输入连接，那么仅权重参数就有 \(1000\times1000 = 100\) 万个，再加上每个神经元的偏置参数，总参数数量会更多.
- **Difference**：neurons are primarily responsible for processing and transmitting information, which are non-linear changes to input signals by activating functions, thereby modeling complex data.Parameters are constantly adjusted through the training process to find an optimal set of values that will allow models to better integrate training data and have good generalizations.In other words, the neurons are the structural components of the model, while the parameters are adaptable elements used to optimize the performance of the model.
