# Customize Thread Pool Questions

## arthas

Find Target Thread Pool

```bash
# Track how the thread pool is called using the tt command (e.g. execute method), get instance reference：

# tracking thread method calls up to 10 times (print data from INDEX and more)
tt-t org.springframe.scheduing.concilirent. hreadPoolTaskExecutor execution - n 10

# Replace INDEX with the capture record index (e.g. 1006, 1009, These are ThreadPoolTaskExecutor instances)
tt -i 1006 -x 2
# See bean name (no thread pool configuration or thread-pool name prefix)

# View instance threadPool configuration (replace INDEX with target index) (you can also see threadPrefix for threadNamePrefix)
tt -i 1012 -w 'target'
# View only threaded pool name (example: member-common-sync-thread-pool-)
tt -i 1012-w 'target. hreadNamePrefix'
```

Next, find target threads

```bash
# Find threaded threads that include target prefix (print information such as ID)
thread-all | grep "member-common-synd-thread-pool-"
# View the specific execution content of the thread, replace 131 with actual thread ID
thread 131
# Stacks showing how threads are executed (e.g. database operations, business logs, etc.), helping to locate if there are time-consuming.
```

Monitor the dynamic performance of threads

If you need to keep track of the thread status change, you can use thread-b commands to monitor the blocking thread, or combined watch commands to monitor how the thread is executed
when the thread executes the method, auto-output parameters, return values, and execution times to analyze whether there is a timeout or an anomaly.
