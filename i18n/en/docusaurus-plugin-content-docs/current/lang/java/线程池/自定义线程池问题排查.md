# Customize Thread Pool Questions

## arthas

Find Target Thread Pool

```bash
# Track how the theme tool is called using the tt command (e.g. execute method, get instance reference：

# tracking thread methods calls up to 10 times (print data from INDEX and more)
tt-t. pringframe.scheduing.conciliation. hreadPoolTaskExecutor execution - n 10

# Replace INDEX with the capture record index (e.g. 1006, 1009, These are ThreadPoolTaskExecutor instances)
tt -i 1006 -x 2
# See bean name (no thread pool configuration or thread-tool name prefix)

# View instance threadPool configuration (replace INDEX with target index) (you can also see threadPrefix for threadNamePrefix)
tt -i 1012 -w 'target'
# View only threaded pool name (example: member-commune-sync-thread-pool-)
tt -i 1012-w target. hreadNamePrefix'
```

Next, find target threads

```bash
# Find threads that include target prefix (print information such as ID)
thread-all | grep "member-common-synd-thread-pool-"
# View the specific execution content of the thread, Replace 131 with actual thread ID
thread 131
# Stacks showing how threads are executed (e). Database operations, business logs, etc.), help to locate if there are time-consuming.
```
